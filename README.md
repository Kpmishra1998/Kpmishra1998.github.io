# kpmishra1998.github.io

Personal academic website of Kaibalyapati Mishra, served with GitHub Pages.

## Files

- `index.html` – Home (bio, news, teaching)
- `research.html` – Publications, working papers, reviews
- `writing.html` – Op-eds and media
- `conferences.html` – Conference presentations
- `resources.html` – Useful links
- `assets/style.css` – Shared styling
- `assets/photo.jpg` – Profile photo (add your own)

## Publishing

1. On GitHub, create a new public repository named exactly `Kpmishra1998.github.io`.
2. Upload all files in this folder (keep the `assets` folder) using **Add file → Upload files**, then commit.
3. Go to **Settings → Pages**, set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. The site goes live at `https://kpmishra1998.github.io` within a minute or two.

## Updating

Edit the relevant `.html` file on GitHub (pencil icon), commit, and the site refreshes automatically. To add a paper, copy an existing `<li>…</li>` line and change the text.
